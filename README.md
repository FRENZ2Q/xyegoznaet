# CD Tracker (Fabric, Minecraft 1.21.4)

Показывает кулдауны предметов у противников, в том числе кастомных предметов сервера.
Меню: клавиша **J**. Конфиг: `config/cdtracker.json`.

Сборка: JDK 21 + Gradle 8.12+: `gradle wrapper --gradle-version 8.12` и `./gradlew build`.
Готовый мод: `build/libs/cdtracker-1.0.0.jar` (не -sources). Нужен Fabric API.
Без установки Gradle: залей проект на GitHub, вкладка Actions соберёт jar.
